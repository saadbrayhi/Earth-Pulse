# Shared website data

Pages and components import these modules instead of defining copies of study facts.
There is no global provider or database: the same modules work in server and client components.

| Change                                                                | Source                                                                                                 |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Dates, bounds, product, polarization, counts, previews, thresholds    | `public/data/analysis.json`, generated by `processing/scripts/analyze_radar.py`; exposed by `study.ts` |
| Observation list, radar view labels, category labels                  | `study.ts`, derived from the report                                                                    |
| Branding, challenge, navigation routes                                | `project.ts`                                                                                           |
| Public resource URLs                                                  | `files.ts`                                                                                             |
| External reference links and credits                                  | `sources.ts`                                                                                           |
| Discovery and reference-access reports                                | `supplemental.ts` (import only where needed)                                                           |
| Page metadata, headings, stories, scientific notices and explanations | `../content/`                                                                                          |
| Theme names, preferences and palette tokens                           | Existing `../lib/themes.ts` and `../styles/theme.css`                                                  |

Do not manually copy statistics, dates, geographic coordinates or thresholds into JSX.
Regenerate the analysis when source observations change; do not edit generated values by hand.
The explorer still loads legacy `metadata.json` and verifies its location, dates, bounds
and threshold against the report before showing imagery. Both must describe the same study.

Keep helpers and validation in `../lib/`, and transient UI state (opacity, selected layer,
swipe position) in the relevant components. Import specific modules rather than adding a
barrel that pulls supplemental reports into every client bundle. ESLint prevents direct
`public/data` imports outside this folder.
